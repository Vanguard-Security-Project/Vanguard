# Vanguard
## 🛠️ Remediation & System Hardening

### Active Directory Automated Remediation (`Fix-ADSecurity.ps1`)

This PowerShell script automates key remediation and security hardening steps across Active Directory environments.

#### Usage:
Run the script from an elevated PowerShell session (Administrator) on a Domain Controller or management workstation:

```powershell
.\Fix-ADSecurity.ps1
```
